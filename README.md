# Team-Landkarte

Beispielprojekt der KI Business School, Modul 4, Woche 4 (25.11.2026).

**Damit üben wir zwei Dinge:**

1. Ein Projekt über GitHub teilen: als Vorlage („Use this template“) oder mit Einladung („Settings → Collaborators → Add people“).
2. Einen Skill nutzen, der mit dem Projekt mitreist: Wer das Projekt in Claude Code öffnet, kann sofort `/seiten-check` aufrufen.

**Achtung, mit Absicht eingebaut:** Die Seite hat ein paar Schwächen. Der Seiten-Check soll sie finden.

Auf Vercel: Projekt importieren, keine Einstellungen nötig, die Seite ist eine einzige `index.html`.
