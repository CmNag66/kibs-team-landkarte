# Die Modul-4-Wand

Beispielprojekt der KI Business School, Modul 4, Woche 4 (25.11.2026): Eine Website, an der alle
gleichzeitig bauen. Live: **https://cmnag66.github.io/kibs-team-landkarte/**

## So machst Du mit

1. Einladung annehmen: https://github.com/CmNag66/kibs-team-landkarte/invitations
2. In Claude Code einen neuen Chat mit diesem Repository starten.
3. Sagen: „Bau meine Karte für die Wand.“ Claude fragt nach, legt `karten/<vorname>.html` an und pusht.
4. Nach etwa einer Minute ist Deine Karte auf der Wand.

Jede Person hat ihre eigene Datei. Deshalb können 30 Leute gleichzeitig pushen, ohne sich zu stören.
